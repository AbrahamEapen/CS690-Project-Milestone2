     Plan: S-3 ranked applicants with a minimum flag (Deliverable 4a draft)

     Written by Claude Code (Claude Opus 5.5) from docs/design/S-3.md and
     AGENTS.md, before any code was edited. To be reviewed by the team, then
     saved as docs/plans/S-3-plan.md.

     Context

     S-3 acceptance tests are locked (m2-tests-locked, red run: 6 S-3 failed, 4
     S-1 passed). This plan builds S-3 in seven bounded tasks. Tasks 1 to 6 each
     make one AC test pass. Task 7 adds the D13 demo seed and the README
     section "Try the story".

     How

     Files created
     - src/jobsboard/ranking.py. Named settings FLAG_TEXT, FIT_SCORE_MIN,
       FIT_SCORE_MAX, SKILL_SYNONYMS (D9). The Candidate and RankedEntry frozen
       dataclasses (§4). InvalidFitScore, DuplicateApplication and InvalidSkill,
       all subclassing ValueError, with attributes named after their
       constructor parameters (D3, D9). Private helpers _validate_skills and
       _validate_fit_score (§5, D10). _normalize/_skill_key (R1, D7).
       rank_applicants (R1 to R5).
     - src/jobsboard/ranking_store.py. PostingNotFound(posting_id) (D9),
       RankingStore (D5, D11), and seed_demo(store, ranking_store) (D13).

     Files changed
     - src/jobsboard/api.py. Add a module-level ranking_store = RankingStore()
       next to store (D12). Add the route GET /postings/{posting_id}/ranked. Add
       a 404 handler that returns {"detail": {"error": "posting_not_found"}}
       (§4). Seed the demo when os.environ.get("JOBSBOARD_DEMO") == "1" (D13).
       The S-1 routes don't change.
     - README.md: add a "Try the story" section (Task 7 only).

     Files that must not change: src/jobsboard/pipeline.py,
     src/jobsboard/__init__.py, tests/, docs/design/, backlog/, evidence/,
     LEDGER.md, prompts/, AGENTS.md, CLAUDE.md, .claude/, requirements.txt.

     Data shapes
     - Candidate(application_id: str, skills: frozenset[str], fit_score: int).
       It has no __post_init__ check. rank_applicants validates all input first,
       so it can raise the first problem in list order (D3).
     - RankedEntry(application_id: str, fit_score: int, meets_minimum: bool, 
       flag: str | None, missing_required: tuple[str, ...]).
     - Skill key: n = s.strip().casefold(). A skill whose n is in a
       SKILL_SYNONYMS group uses that group (a frozenset) as its key. Otherwise
       the key is n (R1, D1, D7).
     - Required skills are grouped by key, so each key counts as one requirement
       (D1). A missing requirement shows the trimmed posting spelling that
       sorts first by (casefold(), spelling). missing_required is sorted by the
